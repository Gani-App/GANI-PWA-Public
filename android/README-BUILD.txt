GANI ANDROID STUDIO PROJECT

This project wraps the v25 offline-completion workspace as a native Android application.

BUILD REQUIREMENTS
- Android Studio or Android SDK
- JDK 17+
- Gradle/Android Gradle Plugin dependencies

CURRENT ENVIRONMENT NOTE
An APK is NOT claimed here because the current runtime has not established an Android SDK/Gradle build environment.

ANDROID STUDIO
1. Open this directory as a project.
2. Allow Gradle sync to complete.
3. Build > Build APK(s).
4. Use debug build for testing.
5. Production signing must remain under the owner's control.

The application loads bundled assets locally and can later connect to HTTPS backend endpoints.
No API key or password belongs in the Android assets.
