07 / FAQ

Waxyaabaha qof walba ugu dambayn weydiinayo.

Jawaabaha muhiimka ah si toos ah ayaa loogu keenay bogga, si “xogtaas meel kale ka raadi” uusan u noqon feature-ka ugu weyn.

GANI ma iibisaa account-ka si toos ah?

Qaabkan website-ku wuxuu GANI u dhigaa meel discovery, comparison, tracking iyo support ah. Iibsiga kama dambaysta ah waxaa lagu xiriirin karaa provider-ka rasmiga ah marka integration-ka dhabta ahi diyaar noqdo.

Sideen u ogaadaa adeegga la xaqiijiyey?

Verification Center-ku wuxuu qeexayaa hubinta aqoonsiga provider-ka, xeerarka, refund/payout, support/SLA, isbeddelada iyo audit trail.

Website-ku ma kaydiyaa password-yada account-yada?

Noocan standalone-ka ahi ma dalbanayo mana kaydinayo credentials-ka trading-ka. Xogta profile-ka iyo records-ka demo-ga ah waxay ku kaydsan yihiin browser-kaaga.

Maxaa dhacaya haddii xeer provider is beddelo?

Qaabka v10 wuxuu leeyahay Change Alerts iyo evidence-log architecture oo loogu talagalay in isbeddel la diiwaangeliyo laguna ogeysiiyo user-ka marka backend-ka la xiro.

Ma soo dejisan karaa xogtayda?

Haa. Dashboard-ka qaybta Privacy & Security wuxuu leeyahay export JSON iyo tirtiridda xogta browser-ka.

Website-kan hadda backend ma leeyahay?

Faylkan waa standalone frontend oo shaqeeya browser-ka. Backend, payments, KYC iyo provider APIs waa integrations gaar ah oo lagu xiro marka adeegyada rasmiga ahi diyaar yihiin.

PLATFORM DOCUMENTATION

Website-ka waxa loo sii diyaariyey inuu noqdo mashruuc la maamuli karo.

Marka project-ku weynaado, UI badan kaligeed waxba ma xalliso. Waxaa loo baahan yahay architecture, release discipline, content governance, QA iyo integration boundaries. Qaybahan v12 ayaa taas caddeynaya.

Architecture principle

Frontend-ku wuxuu qabtaa presentation, local interactions iyo state demo. Backend-ka mustaqbalka wuxuu qabtaa persistence, authentication, provider synchronization, admin permissions iyo server-side audit.

Data principle

Provider iyo offer data waa inay yeeshaan source, review timestamp, freshness status iyo verification state. Xog aan hubin waa in aan loo soo bandhigin sidii xaqiiqo la xaqiijiyey.

Release principle

Nooc kasta waa inuu leeyahay feature inventory, known limitations, regression checklist iyo restore/rollback plan marka production deployment dhab ahi jiro.

Accessibility principle

Keyboard navigation, focus states, readable contrast, semantic labels iyo responsive interaction waa in ay noqdaan qayb ka mid ah system-ka, ma aha qurxin dambe.

Security principle

Standalone frontend-kan ma ururiyo trading credentials. Sensitive authentication iyo account secrets waa inay ku ekaadaan server-side secure integration marka adeegga saxda ahi jiro.

Operations principle

Content, verification, support, provider onboarding, audit iyo release queues waa in si kala cad loo maamulo marka admin backend la dhiso.
